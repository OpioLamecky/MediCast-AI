# MediCast AI — Frontend Application

This directory contains the React 18 single-page application for **MediCast AI**, built with Vite, Tailwind CSS, Radix UI, and Supabase.

For complete documentation, deployment details, and backend inference instructions, please refer to the primary project [README.md](../README.md).

---

## Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
